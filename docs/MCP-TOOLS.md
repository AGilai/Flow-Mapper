# MCP tool catalogue

Generated by `npm run docs:mcp` from the 64 registered tools: do not edit by hand (a test fails when it is stale).
Start with [AGENTS.md](../AGENTS.md). Every tool that takes `env` requires it: a call without one fails with the list of your environments (there is no default). `*` marks a required argument.

## Start and share

- **`whoami`**: The user this connection acts as (the owner of the token), whether they are an admin, and the token scope (user | harvester). No args.
- **`list_envs`**: List environments with their kind ('sealed': filled by harvesters, read-only for manual edits; 'design': created by a copy, editable), the source and date it was copied from, its subsystems (groups) counts and colour (a slot 1..10 with its name; the UI shows it on flow tabs). No args.
- **`create_env`**: Create a design environment by copying another one. Args: `name*` (string), `source` (string), `mode*` ("blank" | "components" | "full"), `groups` (object[]), `levels` (string[]), `behaviour` (boolean), `entryPoints` ("keep" | "none"), `infraGroupPath` (string), `services` (object[]).
- **`share_env`**: Share a design environment you own (or as an admin): `members` replaces the list of people with access ([{user: id or exact name, role: 'viewer' | 'editor'}]; viewers read, editors also open and apply drafts), `published` makes it readable by everyone signed in. Args: `env*` (string), `published` (boolean), `members` (object[]).
- **`set_env_color`**: Set the colour of an environment (any kind; an annotation, no draft needed): a slot 1..10 (1 Teal, 2 Orange, 3 Violet, 4 Rose, 5 Green, 6 Brown, 7 Steel, 8 Plum, 9 Pine, 10 Navy) or null for automatic (follows creation order). Args: `env*` (string), `color*` (integer | null).

## Design: drafts

- **`open_draft`**: Open a draft of a design environment (sealed environments take none): with the slug of an open draft it returns that draft, otherwise it creates one (name required). Args: `env*` (string), `name` (string), `slug` (string).
- **`list_drafts`**: Drafts of an environment with their op counts, authors and +added -removed ~changed counts. Args: `env*` (string), `status` ("open" | "all").
- **`edit_in_draft`**: Append whole-item ops to an open draft: [{op: 'upsert' | 'delete', anchor, service?, data?}] (1..5000, all or nothing). Args: `env*` (string), `draft*` (string), `ops*` (object[]), `author` (string).
- **`draft_changes`**: What an open draft changes in its environment: counts and one item per added / removed / changed anchor (children of an added component are listed under it, not counted; `stale` = the item changed in the environment since the draft touched it, apply overwrites it). Args: `env*` (string), `draft*` (string).
- **`apply_draft`**: Apply an open draft to its design environment in one transaction: one delta per touched service (a full manifest for a new one), DTOs, schemas, flow names, one summary changelog row. Args: `env*` (string), `draft*` (string), `dryRun` (boolean).
- **`discard_draft`**: Close a draft without applying it (its ops stay for the record). Args: `env*` (string), `draft*` (string).

## Design: from documents

- **`import_mermaid`**: Import a Mermaid `sequenceDiagram` into an open draft of a design environment (sealed ones refuse: 409 ENV_SEALED). Args: `env*` (string), `draft*` (string), `text*` (string), `matches` (object), `groupPath` (string), `dryRun` (boolean).
- **`import_preview`**: What importing an endpoint or component from another environment into a draft would bring: counts, the items with why each comes along, what is already in the design, what stays a reference, warnings. Args: `env*` (string), `draft*` (string), `source*` (string), `anchor*` (string), `groupPath` (string).
- **`import_into_draft`**: Import an endpoint (ing:) or component (svc:) from another environment into an open draft of a design (get the preview first with import_preview). Args: `env*` (string), `draft*` (string), `source*` (string), `anchor*` (string), `groupPath` (string).
- **`apply_import_plan`**: Turn an HLD import plan (docs/DESIGN-IMPORT.md, planVersion 1) into ops of an open draft: new components (manifests, inlined), extensions of copied components, flows, DTOs, schemas, subsystems the environment lacks (environment.groups) and abstract links (links, between subsystems / components / endpoints; a bad link is a warning and is skipped; flow relations wait for 0.28.2). Args: `env*` (string), `draft*` (string), `plan*` (object), `dryRun` (boolean).
- **`get_marks`**: What is new / changed / removed in a design environment, per anchor (svc:<s>, ing:<s>/<id>, egr:..., dto:..., evt:<type>, ...), with a phrase of what changed (`what`, `was`), ghosts of removed items and counts. Args: `env*` (string), `against` ("baseline" | "source"), `draft` (string), `prefix` (string), `fields` (boolean).

- **`apply_plan_links`**: Re-read the links of a kept import plan into an open draft: the plan's `links` become abstract links (link:<id>). Args: `env*` (string), `draft*` (string), `from` (string).

## Design: settings

- **`set_subsystem_settings`**: Set the label, icon (platform, agent, network, cloud, shield, database), about (Markdown-lite description) and order of subsystems: `subsystems` is the list in display order. Args: `env*` (string), `subsystems*` (object[]), `draft` (string).
- **`set_levels`**: Name the levels of an environment, outermost first (1 to 4 names of at most 40 characters, e.g. Args: `env*` (string), `levels*` (string[]).

## Read the map

- **`search`**: Find services, functions, endpoints (by bind key), channels and resources by text. Args: `draft` (string), `query*` (string), `env*` (string), `limit` (integer).
- **`list_services`**: List services with version, team and link-health numbers. Args: `draft` (string), `env*` (string).
- **`get_service`**: A service's ingress (with callers), egress (with targets), resources, channels and functions. Args: `draft` (string), `service*` (string), `via` (string), `env*` (string).
- **`list_entry_points`**: Ingress points where flows start (public APIs, crons, client socket events, and anything nothing else calls). Args: `draft` (string), `env*` (string).
- **`trace_flow`**: Follow a flow from an ingress or function (in a design environment a message into a copied endpoint whose behaviour lives in its source carries `reference` {anchor, source}, and `partial.steps` lists them: those steps' behaviour is not in the design; `start.name` is the flow's name; egress messages carry `via`, the wrapper chain; display only): ordered calls, DB access, REST calls and async hops across services. Args: `draft` (string), `service*` (string), `ingress` (string), `fn` (string), `event` (string), `expand` (string[]), `scope` ("intra" | "full"), `detail` ("simple" | "external" | "full"), `choose` (object), `open` (string[]), `dbOpen` (string[]), `unfold` (string[]), `env*` (string), `maxMessages` (integer), `frontier` (boolean).
- **`find_paths`**: Service-level paths from one service to another, including through queues and topics. Args: `draft` (string), `from*` (string), `to*` (string), `env*` (string), `limit` (integer).
- **`get_endpoint_info`**: One ingress endpoint (producers of its events carry `via` when they call through a wrapper): its handler, a link to the handler's code in the repo, its DTO slots (a queue takes one message; a GET its path/query params and a response body), and for event consumers each event type with its handler, derived/declared producers, status (ok, unhandled, never, declared-only) and Message DTO. Args: `draft` (string), `service*` (string), `ingress*` (string), `env*` (string).
- **`get_call`**: One call out of a component (an egress): the steps that make it (function, step number, operation) and the endpoints it reaches. Args: `env*` (string), `service*` (string), `egress*` (string), `draft` (string).
- **`get_channel`**: A topic, queue, exchange or event bus by key (for an exchange page, the publishers, bindings and callouts, use get_exchange): publishers, subscriptions/rules with event filters, consumers, event types passing through, problems, and `flow`: merged subscription rows (declarations that disagree are named), a grid of event type x destination (handled, filtered, arrives with no handler) and a one-sentence summary with callouts. Args: `draft` (string), `env*` (string), `key*` (string).
- **`get_exchange`**: A RabbitMQ exchange page (0.19.0) by key `amqp:<exchange>` or bare name: type, vhost, durable, alternateExchange, `publishers` (one row per service and routing key: `reaches` the bindings that route it, `dropped` when none does, publishedIn), `bindings` (binding key to queue, consumers with handlers, `matchedBy` the published keys, `noPublisher`) and `callouts` (a published key that matches no binding is dropped or goes to the alternate exchange; a binding no harvested publisher feeds). Args: `draft` (string), `env*` (string), `key*` (string).
- **`get_store`**: A data store by bind key (e.g. Args: `draft` (string), `env*` (string), `key*` (string).
- **`list_clients`**: How services reach data stores (and non-store targets): one row per client site with access mode, the service's own driver, the wrapper lib and the driver bundled in it, and the `via` wrapper chain; rows carry `mixed` when a service has two majors of one driver package. Args: `draft` (string), `env*` (string), `store` (string), `service` (string), `driver` (string), `driverMajor` (string), `lib` (string), `accessMode` ("direct_driver" | "shared_lib" | "self_implemented_wrapper" | "third_party_lib"), `via` (string).
- **`get_resource_keys`**: The key templates of one Redis instance (#29), grouped by the service that writes them: groups 'No harvested writer' and 'Shared: written by N services' first, then one per owner. Args: `draft` (string), `env*` (string), `resourceId*` (string), `dbIndex` (integer), `query` (string), `problems` (boolean), `service` (string).
- **`event_types`**: Event types in the environment: who publishes each one and which consumers (and handlers) receive it after subscription filters. Args: `draft` (string), `env*` (string), `type` (string).
- **`inventory`**: Every object: services, topics/queues/buses, data stores and event types, with connections and problem counts. Args: `draft` (string), `env*` (string), `type` ("service" | "channel" | "store" | "event"), `query` (string).
- **`link_health`**: Dangling egress, orphan ingress, unbound channels, broken bindings, ambiguous matches and per-service coverage. Args: `draft` (string), `env*` (string), `service` (string), `assumed` (boolean), `basis` (string).
- **`changelog`**: Recent changes to the map (ingests and edits), newest first. Args: `env*` (string), `service` (string), `limit` (integer).

## Subsystems and flows

- **`get_subsystems`**: The subsystems of an environment: {levels, subsystems: [{key, label, icon, about?, order, derived, components}], notSet}. Args: `env*` (string), `draft` (string).
- **`get_subsystem_map`**: The environment at subsystem level: boxes (subsystem, its components, internal / out / in / dangling call counts), lines (every call between two subsystems rolled up by transport and mode, with the calls under it, counted once) and the abstract links. Args: `env*` (string), `draft` (string).
- **`list_abstract_links`**: Abstract links of a design (links drawn at subsystem level, link:<id>): ends, state (abstract, partial, ready, refined, broken), problems, and the calls that refine them. Args: `env*` (string), `draft` (string), `subsystem` (string).
- **`suggest_refinements`**: Up to 5 ways to refine one abstract link: these are existing calls between the two ends (pick one with edit_design refine-link `use`, or make a call with refine-link `call`), then components of an open end that make no such call yet (narrow an end with refine-link `from` / `to`). Args: `env*` (string), `id*` (string), `draft` (string).
- **`list_flow_relations`**: Typed relations between two entry-point flows of a design environment (rel:<id>): contradicts, variant-of, supersedes, same-topic, with an optional note. Args: `env*` (string), `draft` (string), `service` (string), `ingress` (string), `type` ("contradicts" | "variant-of" | "supersedes" | "same-topic").
- **`get_flow_names`**: The names of the flows of an environment ({service, ingress, name, author, updatedAt}); the same names list_entry_points and trace_flow carry. Args: `env*` (string), `draft` (string).
- **`set_flow_name`**: Name a flow (an entry point: service + ingress); name '' removes it. Args: `env*` (string), `service*` (string), `ingress*` (string), `name*` (string), `draft` (string).
- **`set_description`**: Save the AI description of a flow (no callee) or of one service in it (callee: the service name, 'service:handler' for one delivery, or a step key '#step:<from>><to>|<label>|<transport>' built from one message of trace_flow, for one arrow). Args: `draft` (string), `service*` (string), `ingress*` (string), `callee` (string), `text*` (string), `title` (string), `model*` (string), `env*` (string).

## Export

- **`export_mermaid`**: One flow as Mermaid `sequenceDiagram` text (every environment, a sealed one too; a design as an open draft would leave it with `draft`): the full trace from an entry endpoint. Args: `env*` (string), `draft` (string), `service*` (string), `ingress*` (string).

## Collaborate

- **`list_comments`**: The discussion under a flow (service + ingress): comments oldest first, each with its author, time, optional step key, plain `text` and sanitized `html`, and its replies (one level). Args: `env*` (string), `service*` (string), `ingress*` (string), `draft` (string), `since` (string).
- **`add_comment`**: Add a comment (or a reply with parentId) under a flow. Args: `env*` (string), `service*` (string), `ingress*` (string), `author` (string), `body*` (string), `step` (string), `steps` (object), `parentId` (integer), `draft` (string), `createdAt` (string), `externalId` (string), `externalSource` (string), `authorExternalId` (string), `parentExternalId` (string), `resolved` (boolean), `resolvedBy` (string), `resolvedAt` (string).
- **`resolve_comment`**: Resolve or reopen a discussion: id is a top comment (a reply cannot be resolved alone; its thread follows). Args: `env*` (string), `id*` (integer), `author` (string), `resolved*` (boolean).
- **`get_notes`**: The Notes of a flow (service + ingress): one rich document per flow that tells its story (purpose, how it works, decisions, open questions). Args: `env*` (string), `service*` (string), `ingress*` (string), `version` (integer), `history` (boolean).
- **`set_notes`**: Write the Notes of a flow as a new version (the whole document: read get_notes first and send it back changed). Args: `env*` (string), `service*` (string), `ingress*` (string), `body*` (string), `base_version` (integer), `author` (string), `draft` (string).
- **`list_action_items`**: The action items under a flow (service + ingress): number, owner, description, status (open | progress | done | dropped), due (YYYY-MM-DD or null), step key, the commentId it was made from, source (human | ai), who created and last changed it, and the events (created, closed, reopened, dropped). Args: `env*` (string), `service*` (string), `ingress*` (string), `draft` (string).
- **`add_action_item`**: Add an action item under a flow. Args: `env*` (string), `service*` (string), `ingress*` (string), `owner*` (string), `description*` (string), `status` ("open" | "progress" | "done" | "dropped"), `due` (string), `step` (string), `commentId` (integer), `author` (string), `draft` (string).
- **`update_action_item`**: Change an action item by id (from list_action_items): owner, description, status, due (null clears), step (null clears). Args: `env*` (string), `id*` (integer), `author` (string), `owner` (string), `description` (string), `status` ("open" | "progress" | "done" | "dropped"), `due` (string | null), `step` (string | null), `draft` (string).
- **`list_open_questions`**: The open questions of an environment: every list item of a '## Open questions' section in the `about` of a component or a subsystem, as {count, questions: [{kind: component | subsystem, id (component name or subsystem key), label, subsystem, text, index (position among that item's questions), line}]}. Args: `env*` (string), `draft` (string).
- **`list_users`**: The users registry: id, name, aliases and external ids (e.g. Args: `query` (string).
- **`list_mentions`**: The comments that @mention a user, across every environment, newest first (plus `about`: the About of components and subsystems that mention them, {env, kind, id, label, text}, and `notes`: the flows whose Notes mention them, {env, service, ingress, label, text}; both never unread): comment id, env, flow (service + ingress), step key, who wrote it, plain text and html, time and `unread` (a mention is unread until that user has seen it in the UI). Args: `user*` (string), `unread` (boolean), `env` (string), `limit` (integer).

## Harvest (sealed envs, harvester token)

- **`ingest_manifest`**: Submit a harvester manifest (kind full or delta) to a sealed environment; a design environment takes only dryRun (edit a design through a draft). Args: `manifest` (object), `manifests` (object[]), `dryRun` (boolean), `draft` (string).
- **`load_dtos`**: Store DTO JSON (replaces an existing one). Args: `env*` (string), `dtos*` (object[]), `dryRun` (boolean), `draft` (string).
- **`load_schemas`**: Store data-store schemas: [{key, source: 'code' | 'db' | 'manual' (default code), content}]. Args: `env*` (string), `schemas*` (object[]), `dryRun` (boolean), `draft` (string).

## Bugs in Flow-Mapper

- **`report_bug`**: Report a bug in Flow-Mapper. Args: `title*` (string), `description` (string), `steps` (string), `severity` ("S1" | "S2" | "S3" | "S4"), `appVersion` (string), `env` (string), `reporter` (string), `links` (object[]), `log` (string).
- **`list_bugs`**: Bugs sorted by priority. Args: `status` (string), `priority` (string), `reporter` (string), `updatedSince` (string), `service` (string), `version` (string), `q` (string), `open` (boolean).
- **`get_bug`**: One bug with links, attachments, comments and allowed status transitions. Args: `id*` (integer).
- **`update_bug`**: Change status (respecting the workflow), severity, priority override (null clears), assignee, fixedInVersion, resolution or links. Args: `id*` (integer), `status` (string), `severity` (string), `priority` (string | null), `assignee` (string), `fixedInVersion` (string), `links` (any[]), `resolution` (object), `comment` (string).
