Frame 16. Maximize a flow (new)

Maintainer: "a maximize button per flow … renders the flow and its comments/action items, all the tab on all the screen, and then a floating button saying exit full screen … for clarity and focus".

  • The button is an icon at the right end of every flow header, after Export: four corners pointing out, tooltip "Maximize (F)". The key F does the same when the caret is not in a text field.
  • Maximized the open tab takes the whole browser window. The top bar, the left rail, the Flows list and the tab strip are hidden. The page asks the browser for real full screen too; if the browser refuses, it still fills the window.
  • One scrolling column: the flow header (sticky, with the step controls), the diagram at full width and its natural height, then the description, Related flows, Action items and Comments, all open, with no 40vh cap. Text stays at reading width (1100 px) and centred.
  • "Exit full screen" floats at the top right over everything, dark pill with Esc. It fades to 55% while the pointer is still and comes back on movement. Esc exits (unless an editor or a dialog has the focus, which Esc closes first). Leaving the browser's own full screen exits too.
  • The floating bug button stays, bottom right. The state is in the URL (max=1), so a link or a reload opens maximized (window-filling; browsers only allow real full screen after a click). Switching tab is not possible while maximized: exit first.
