Frame 32. Component icons (CR #144)

A component can carry an optional icon: one of a small built-in set, or a user-supplied SVG / data URL. It shows beside the name in the lifeline head, the System-map box and the Info-pane header. Data is invented; colours are the frame 31 domain families.

  1. Built-in set = the vendors' own icons (32a). The maintainer rejected generic glyphs, so each built-in is the official mark, shown in its own colours: AWS Architecture Icons, one per service (19 here: Lambda, EC2, ECS, EKS, SQS, SNS, EventBridge, Step Functions, DynamoDB, RDS, ElastiCache, S3, API Gateway, CloudFront, Kinesis, Cognito, KMS, Secrets Manager, IAM; the full package has ~300 and any can be added the same way), plus HashiCorp Vault, Auth0, MongoDB, Redis, PostgreSQL, MySQL, Elasticsearch, RabbitMQ and Apache Kafka. Files and licence terms are in frames/assets/icons/SOURCES.md. API values are the file names without extension: aws-lambda, vault, auth0, kafka, ...
  2. Colours and dark mode. Icons are never recoloured, so the old "ink glyph" rule is dropped. Exceptions, each a plain tile behind the mark and nothing else: Vault (yellow triangle, too faint on a light header) sits on a dark slate tile; Auth0 (the source file, simple-icons, is a colourless path) is drawn from the same path filled with Auth0's brand orange (#EB5424). The AWS squares carry their own coloured background and need no tile. In dark theme the two marks that are near-black (Kafka, MySQL) also sit on that white tile. A user-supplied logo gets the white tile with a hairline border so a dark mark survives dark theme (32a, mailer).
  3. Placement and size (32b, 32c, 32d). The icon sits left of the name: 14px in heads and boxes (AWS squares are square and keep their rounded corners), 18px in the Info-pane header. Heads stay 100px wide; with an icon the name is left-aligned after it and drops from 11.5 to 10.5px. Components without an icon are unchanged. Family stripe and shade are still the only component colour.
  4. Editing (32d). New Icon row in the Info pane: current icon and name; clicking opens a picker with a search field, then the set grouped: Products (Vault, Auth0, MongoDB, ...) and AWS by category (Compute, Containers, Application integration, Databases, Storage, Networking, Analytics, Security). Searching filters across all groups and drops empty ones. Below the groups: Custom SVG... (paste SVG markup or a data URL, live preview) for anything not built in, and None. The API accepts a built-in name, an <svg> string or a data:image/... URL (size-limited); anything else is 422 BAD_ICON, shown inline.
  5. Accessibility. The image is decorative (empty alt); the name is always the label.
