Decisions

  1. Three-way switch, Simple first and default. External stays reachable; the badge and Expand here need it. The API default stays detail=external.
  2. Arms flattened, decisions omitted. No alt frames; the header note says how many were folded in and links to External.
  3. Consolidation key is caller, target, op and key template. Same caller and same store with different ops merge into one *N get, set, del arrow at the first place, even when not adjacent.
  4. “Also at” uses code locations (fn · file:line), not step numbers, because the other occurrences are not drawn in Simple. “Seen in External at steps” is added when it maps.
  5. Repeat marker for a second call to the same service and endpoint from a different caller. Click jumps to the first; Expand here unfolds it in External. Also offered on External and Full repeats.
  6. Hidden badge counts internal and frontier steps removed per service. Duplicates folded into a count are not counted.
  7. Problems are never hidden. Gaps, broken, unhandled and blocked steps stay in Simple.
