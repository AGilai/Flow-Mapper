Frame 3. Subsystem level: rolled-up calls and abstract links

#/?env=sase-hld&level=subsystems. The same design, one level up. Calls between components roll up into one line per direction and transport. Two links were drawn at this level and have no component yet; one is being refined.

  1. Roll-up is automatic and goes both ways. Every call between components in two subsystems shows here as one line per transport, labelled with the count ("2 calls · http"); thickness grows with the count. Click it to list the calls. Nothing is stored for a roll-up.
  2. An abstract link is a real item, drawn at subsystem level: a name, a direction, sync or async, a description. Its ends are open circles on the box edge: "no component here yet". It can be discussed, and it can be marked New like anything else.
  3. Refine end by end. The panel picks a component for each end, then an endpoint (or a new one). An end that has a component draws into that component's row; when both ends have endpoints, the link becomes an ordinary call at component level and rolls up here like the others.
  4. The assistant suggests ends from the design ("pop-telemetry already sends flow logs to telemetry-ingest over amqp"), so refining usually starts from what's already drawn.
  5. Inside each box, the components are a list with their marks, prod ones muted. Click a name to go down to it at component level.
