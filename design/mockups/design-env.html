Design environments: an HLD for the SASE project

Revision 4: frames 1–9 approved and built (0.24); frame 10 adds references (🔒), importing one level into a design, and partial-flow warnings. Frame 11, decided (rev 5): a pastel colour per component on heads and activation bars; arrows keep the transport colour (option A); colours assigned per environment and stored, so a component keeps its colour and there are no clashes up to 8; past 8 the palette repeats; neutral for client apps, externals and data stores. Static mockup for the maintainer. A design environment is a normal Flow-Mapper environment that holds a high-level design. You start it from any environment (prod, or another design), edit it on the canvas through shared drafts, sketch at subsystem level and refine down to components and endpoints, pull in what's missing from other environments while you work, and discuss any item. Names are illustrative. Tokens, chips, toolbar, tabs and the docked panel are the app's own (0.19.1).

Notes that apply to every frame

  1. Status is computed, not stored. Every environment keeps the revision it was copied from (its baseline). The server compares the current state with the baseline at read time and marks each item New, Changed, Removed, or nothing (unchanged, "From prod" in the meta line).
  2. On every level. Subsystem link, component, endpoint, call, queue, message, a field of a message, a field of a collection. The mark goes on the highest new item only: a new component's endpoints are new by implication and don't repeat the icon, so the page doesn't fill with stars.
  3. The new icon is a small yellow spark, with one short twinkle when the page loads (off with reduced motion). It's the only yellow in the app: --warn stays amber and is never shown as a star.
  4. Words. Environment › subsystem › domain (later) › component › endpoint / message › field. A flow has a name ("Agent connects to POP"); the entry key is secondary. A draft is a named, shared set of changes that is applied in one step.
  5. Harvested environments stay read-only. Edit mode, drafts and import exist only in design environments.
--new (spark)--new-ink (outline, text)--warn (unchanged, amber)
